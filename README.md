# Japanese investment, traced to U.S. states

Interactive map of documented Japanese firm links to U.S. projects and deals (mainly 2014 through 29 October 2026).

Open the live map: https://edg-r.github.io/japan-us-investment-map/

This is a documented reconstruction from company releases, filings, and government records. It is not official FDI stock and does not verify bank transfers from Japan.
